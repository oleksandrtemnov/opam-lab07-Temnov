Завдання 5. Захоплення змінних (Три несподіванки)

Фактичний вивід:
1. Змінна після лямбди:
   Виклик check(50) після зміни threshold на 1000: False
2. Лічильник циклу for:
   Результати виклику лямбд з for: 3 3 3 
3. Цикл foreach по { 0, 1, 2 }:
   Результати виклику лямбд з foreach: 0 1 2 

Пояснення:
1. Змінна після лямбди: Лямбда-вираз захоплює не значення threshold на момент оголошення, а посилання на неї. Під час виклику використовується актуальне значення (1000).
2. Лічильник циклу for: Змінна i існує в єдиному екземплярі для всього циклу. Усі 3 лямбди захоплюють одну й ту ж змінну, яка після завершення циклу дорівнює 3.
3. Те саме з foreach: Ітераційна змінна item створюється заново на кожному кроці циклу, тому кожна лямбда захоплює свою власну копію змінної.

Як виправити пункт 2: Створити локальну змінну всередині циклу:
for (int i = 0; i < 3; i++)
{
    int copy = i;
    actionsFor.Add(() => copy);
}
